*******
Summary
*******

``lib_nn`` is a library of efficient neural network functions developed to maximize the
performance and minimize the memory footprint of neural network inference on XMOS devices.

********
Features
********

* Optimized 8-bit convolution, pooling, fully-connected and elementwise kernels for the XS3 vector unit.
* Reference (portable C) implementations of each kernel, usable on any platform.
